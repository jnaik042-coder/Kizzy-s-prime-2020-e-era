# KIZZY — The 2020 Free Fire Journey

A single-page esports profile website for Kizzy.

## Files
- `index.html` — website structure
- `style.css` — design and responsive layout
- `script.js` — scroll reveal animation

## Run locally
Open `index.html` in Chrome, Edge, Firefox, or any modern browser.

## Publish
Upload all three files to a GitHub repository and enable GitHub Pages.
